# ¿Qué tan bien conoces a Eisner?

Quiz web sencillo (HTML, CSS y JavaScript sin dependencias).

## Cómo usarlo
Abre `index.html` en el navegador, o publícalo con GitHub Pages
(Settings → Pages → Deploy from a branch → `main` / root).

## Cómo editar las preguntas
Modifica el arreglo `questions` al inicio de `script.js`.
